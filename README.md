# GA4 Customer Behavior Analytics Dashboard

A portfolio-ready analytics project that models how a digital team would use Google Analytics 4, Looker Studio reporting, event tracking, conversion tracking, and stakeholder insights to understand customer behavior.

## Highlights

- Interactive customer behavior dashboard with channel and segment filters.
- GA4-style ecommerce funnel from users to purchase.
- Event tracking and conversion tracking documentation.
- Looker Studio reporting brief for stakeholder-ready dashboards.
- Sample GA4 event export data for analysis and QA.

## Run Locally

Open `index.html` in a browser. No build step is required.

## Business Scenario

An ecommerce product team needs a weekly analytics view that connects acquisition quality, event instrumentation, checkout behavior, and revenue outcomes. This dashboard turns GA4-style data into decisions that product managers and marketing stakeholders can act on.
