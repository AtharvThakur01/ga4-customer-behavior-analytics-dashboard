# Looker Studio Reporting Brief

## Dashboard Pages

1. Executive Overview: users, engaged sessions, conversion rate, revenue, and average order value.
2. Acquisition Performance: channel, campaign, source, medium, and conversion mix.
3. Funnel Analysis: page view to purchase drop-off with segment controls.
4. Event QA: event counts, missing parameters, naming drift, and release notes.

## Suggested Data Sources

- GA4 native connector for traffic, events, and ecommerce metrics.
- Google Sheets QA log for tracking instrumentation issues.
- CRM or order export for backend revenue reconciliation.

## Stakeholder Readout

This report is designed for product, lifecycle marketing, and leadership teams. The weekly readout should explain what changed, why it matters, what decision is needed, and which owner should act next.
